# DevOps Learning

This repository documents my practical DevOps learning through hands-on work rather than just course completion.

## Linux

The [Linux section](linux/README.md) contains my OverTheWire Bandit walkthroughs and Linux command reference.

It covers navigation, files, permissions, searching, text processing, encoding, compression, archives, SSH and networking.

## Bash Scripting

The [Bash scripting section](bash-scripting/README.md) contains the four scripting challenges from the Bash module.

Each challenge includes the final script, a brief description, the main technical learning notes and a short set of points I want to keep in mind.

The aim is to show what I built, what the commands are doing and how the Linux fundamentals start turning into repeatable automation.

## Docker

The [Docker section](docker/README.md) documents my Flask, Redis and NGINX multi-container visit-counter project, including Dockerfiles, Compose networking, service replicas, verification and troubleshooting.

## Networking

The [Networking section](networking/README.md) covers an earlier EC2, NGINX and Cloudflare DNS deployment.

## AWS Infrastructure — THREADX

The [AWS section](aws/README.md) contains three CoderCo labs in one project: VPC/public-private networking, ALB and Auto Scaling, then S3 static website hosting with CloudFront, ACM and Route 53. Each assignment has its own architecture Mermaid diagram, implementation walkthrough, verification boundary, incident notes and screenshot-selection guide. The Assignment 2 folder also includes the captured NGINX EC2 user-data script.
