Infrastructure as Code · AWS

Terraform Project 2

An automated EC2 web-server deployment using Terraform, Ubuntu, cloud-init and Apache2. Built to demonstrate infrastructure provisioning and first-boot configuration.

CoderCo · Terraform Assignment 2

Technology Stack

Four components working together to deliver a website on AWS.

01 / DEFINE

Terraform

Defines AWS infrastructure in reusable modules.

02 / PROVISION

Amazon EC2

Runs the Ubuntu 26.04 LTS virtual machine.

03 / CONFIGURE

Cloud-init

Installs and configures software at first boot.

04 / SERVE

Apache2

Serves the custom HTML page over HTTP.

What the Project Includes

The important part is how the infrastructure is created and configured automatically.

Infrastructure and Configuration

  • Terraform EC2 and security-group modules
  • HTTP access through the security group
  • Ubuntu server with a public IPv4 address
  • Cloud-init YAML to install and enable Apache2
  • Custom index.html for the website
  • Terraform variables and outputs
